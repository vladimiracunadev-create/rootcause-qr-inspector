# Referencias técnicas

Fuentes primarias o mantenidas por la entidad responsable:

- [FTC — Scammers hide harmful links in QR codes](https://consumer.ftc.gov/consumer-alerts/2023/12/scammers-hide-harmful-links-qr-codes-steal-your-information): riesgo de sitio falso y descarga maliciosa desde QR.
- [Unicode UTS #39 — Unicode Security Mechanisms](https://www.unicode.org/reports/tr39/): detección de mixed-script y confusables. La implementación 0.1.1 es una heurística parcial y no declara conformidad.
- [WHATWG URL Standard](https://url.spec.whatwg.org/): modelo de parser, host y serialización de URL.
- [RFC 3986 — URI Generic Syntax](https://www.rfc-editor.org/info/rfc3986/): componentes genéricos de una URI.
- [OWASP — Open Redirect](https://owasp.org/www-community/attacks/open_redirect): redirecciones controladas por parámetros y uso dentro de cadenas de phishing.
- [OWASP MASVS — Storage](https://mas.owasp.org/MASVS/05-MASVS-STORAGE/): protección y prevención de fuga de datos sensibles almacenados.
- [OWASP MASVS — Cryptography](https://mas.owasp.org/MASVS/06-MASVS-CRYPTO/): criptografía y ciclo de vida de llaves.
- [OWASP MASVS — Privacy](https://mas.owasp.org/MASVS/12-MASVS-PRIVACY/): transparencia sobre recolección, almacenamiento y uso.
- [JSON Schema Draft 2020-12](https://json-schema.org/draft/2020-12): dialecto usado para el contrato de evidencia.

Estas referencias justifican controles y límites; no convierten el producto en
una implementación certificada de dichos estándares.
