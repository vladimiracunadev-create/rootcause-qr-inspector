# RootCause QR Inspector 0.1.0 para Android

Primera entrega Android instalable del sensor de seguridad QR de la familia
RootCause. Interpreta la carga antes de actuar, aplica 26 señales locales,
separa hechos de hipótesis y permite exportar evidencia redactada.

## Descargar

- `rootcause-qr-inspector-v0.1.0-android.apk`: aplicación para Android 7.0
  (API 24) o posterior.
- `rootcause-qr-inspector-v0.1.0-android.apk.sha256`: checksum para comprobar
  que el archivo descargado coincide con el publicado.

El APK se construye desde la etiqueta `v0.1.0`; GitHub publica una atestación de
procedencia vinculada al workflow. Es una descarga directa instalable y no una
entrega mediante Google Play.

## Prueba funcional recomendada

1. Instala el APK y concede cámara solo al comenzar una inspección en vivo.
2. En **Generar**, crea y comparte un PNG con `https://example.com/documento`.
3. En **Inspeccionar**, importa ese PNG: debe mostrar una lectura normal y
   recordar que normal no significa destino garantizado.
4. Repite con `https://banco.example@evil.example/acceso`: debe explicar
   `authority-userinfo` y `credential-lure-path`, exigir confirmación y no abrir
   el destino automáticamente.
5. Exporta **Evidencia** y confirma que la vista redactada no incluye la carga
   completa ni la URL efectiva.

## Límites

El análisis es local: no consulta reputación, DNS, certificados ni contenido
