# RootCause QR Inspector 0.1.4 para Android

Esta entrega corrige la inspección de códigos pequeños o densos dentro de PDF
y mejora la confirmación y portabilidad de los resultados, sin cambiar el
contrato de investigación ni el formato persistido.

## Novedades

- Rasterizado PDF adaptativo de hasta 4096 px para preservar códigos de barras
  lineales y QR pequeños.
- Confirmación sonora y háptica al validar códigos desde imágenes o PDF, una
  vez por lote y respetando los ajustes de la persona.
- Exportación de Historial e Inventario como HTML autocontenido y legible en
  navegador, además de CSV, JSON y XLSX.
- Enlaces web abiertos explícitamente en el navegador y en una pestaña nueva
  cuando la aplicación se ejecuta en web.
- Fixture PDF sintético con Code 128 compacto y 107 pruebas Flutter aprobadas.
- Corrección del ciclo de vida de temporales: las páginas renderizadas se
  conservan hasta que ML Kit termina de analizarlas.

## Archivos publicados

- `rootcause-qr-inspector-v0.1.4-android.apk`: aplicación para Android 7.0 o
  posterior.
- `rootcause-qr-inspector-v0.1.4-android.apk.sha256`: checksum para comprobar
  la integridad de la descarga.

El workflow del tag repite contrato, estructura, análisis, pruebas y build
release; verifica la firma técnica, adjunta procedencia y publica ambos
archivos únicamente si todos los gates terminan correctamente.

## Límites honestos

El flujo completo se validó en un emulador Android API 36: 5 páginas, 4 códigos
y un Code 128 reconocido en la página 2. Aún falta confirmar audio, vibración,
cámara y rendimiento en un dispositivo físico. La inspección local no consulta
reputación, DNS, certificados ni redirecciones de red. Un resultado sin señales
locales no declara seguro el destino.
