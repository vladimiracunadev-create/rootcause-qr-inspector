# RootCause QR Inspector 0.1.3 para Android

Esta entrega mejora la comprensión del producto sin cambiar el motor local de
investigación, la política de acción ni el formato de los datos existentes.

## Novedades

- **Analizar archivo** inspecciona una imagen, hasta 20 imágenes o un PDF de
  hasta 50 páginas, siempre de forma local y sin abrir destinos.
- Ajustes incorpora español (Chile e internacional), inglés, francés y alemán.
- **Guía rápida de la aplicación** explica las cinco pestañas.
- Inventario incluye ayuda contextual y cuatro pasos claros: crear sesión,
  escanear cada unidad física, revisar cantidades y cerrar/exportar.
- Los resultados describen el destino semántico y destacan el host real antes
  de ofrecer cualquier acción externa.

## Archivos publicados

- `rootcause-qr-inspector-v0.1.3-android.apk`: aplicación para Android 7.0 o
  posterior.
- `rootcause-qr-inspector-v0.1.3-android.apk.sha256`: checksum para comprobar
  la integridad de la descarga.

El workflow del tag vuelve a ejecutar el contrato, el análisis estático, todas
las pruebas y la compilación release antes de publicar el APK. También verifica
la firma técnica y adjunta una atestación pública de procedencia.

## Límites honestos

La inspección local no consulta reputación, DNS, certificados ni redirecciones
de red. Un resultado sin señales locales no declara seguro el destino. La demo
web permite recorrer la interfaz, pero el análisis de imágenes/PDF se admite en
las plataformas móviles nativas.
